# 📚 English Janala

> **An interactive English vocabulary learning platform** built with **HTML, Tailwind CSS, DaisyUI, and Vanilla JavaScript**.
> Users can explore vocabulary by lesson, search words instantly, listen to pronunciations, and learn meanings with examples through a clean and responsive interface.

# ✨ Features

✅ Dynamic lesson buttons loaded from API

✅ Fetch vocabulary by lesson

✅ Search vocabulary instantly

✅ Word details displayed in a responsive modal

✅ English pronunciation using Speech Synthesis API

✅ Loading spinner while fetching data

✅ Active lesson highlighting

✅ Responsive design for Mobile, Tablet & Desktop

✅ Handles empty vocabulary gracefully
